Customer Support Portal - Working Notes
Author: Sarah Johnson
Date: 15 Jul 2026

Need to confirm with support ops before freezing requirements.

Main reason for this project:
- too many customers calling just to check ticket status
- management wants more self-service
- reduce support workload if possible

Things everyone agreed on:
- customer accounts (email/password)
- forgot password via email
- online ticket submission
- customer can check ticket status themselves
- email updates whenever ticket status changes

Discussion points:
- should customers edit tickets after submission?
    -> maybe only while ticket is still Open
    -> once agent starts work, editing should probably be disabled

Support team requests:
- dashboard showing assigned tickets
- ability to transfer tickets between agents
- internal notes (customers should never see these)
- searching by ticket number is important
- filters for priority/status would be useful

Need to ask management:

    * open tickets
    * avg resolution time
    * tickets by priority

Security meeting notes:

- encrypt customer info
- MFA only for staff accounts
- customer MFA can wait
- 15 min session timeout sounds reasonable
